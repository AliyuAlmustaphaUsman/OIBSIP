# Temperature Converter

Oasis Infobyte SIP, Web Development and Designing, Level 1, Task 3.

A web tool that converts a temperature between Celsius, Fahrenheit and Kelvin. Built with HTML5, CSS3 and vanilla JavaScript.

## Features
- Numeric input with validation (empty and non-numeric input show an error message)
- Unit selector (Celsius, Fahrenheit, Kelvin)
- Convert button that shows all three units at once, with unit labels
- Absolute zero check: values below -273.15 °C show a clear message
- Centred, responsive layout with labelled fields

## Run it
Open `index.html` in any browser.
