# Personal Portfolio: Aliyu Almustapha Usman

Oasis Infobyte SIP, Web Development and Designing, Level 1, Task 2.

A responsive personal portfolio built with HTML5 and CSS3 (no JavaScript).

## Sections
- Hero with name, role title and avatar
- About me
- Skills
- Projects (2 cards with GitHub links)
- Education and training
- Contact

## Features
- Sticky navigation with smooth scrolling between sections
- Consistent colour palette and fonts
- Responsive layout for desktop and mobile

## Run it
Open `index.html` in any browser.
