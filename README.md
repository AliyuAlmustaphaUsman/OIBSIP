# Landing Page: Sahel Roast Co.

Oasis Infobyte SIP, Web Development and Designing, Level 1, Task 1.

A responsive, static landing page for a fictional small-batch coffee roaster. Built with HTML5 and CSS3 only (no JavaScript).

## Features
- Sticky navigation bar with 4 links
- Hero section with headline, subheadline and call-to-action button
- Three content sections: Coffees, About, Reviews
- Footer with placeholder contact and social links
- Consistent colour palette (indigo, saffron, light grey)
- Responsive layout using CSS Grid and Flexbox
- Two font sizes for headings and body text, loaded from Google Fonts

## Run it
Open `index.html` in any browser.
